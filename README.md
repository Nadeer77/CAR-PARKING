# 🚗 Car Parking Game

A 3D car parking game developed using **Unity and C#**, featuring 10 levels with different parking challenges, vehicle physics, AI traffic, and pedestrian movement.

## 🎮 Project Overview

Car Parking is a 3D driving game where players must park their vehicle in designated parking spaces. Each level presents different parking challenges, including forward and reverse parking, with AI-controlled vehicles and pedestrians moving around the environment.

## ✨ Features

- **10 Levels:** Progress through 10 levels with different parking challenges.
- **Vehicle Physics:** Implemented vehicle movement and handling using Unity Wheel Colliders.
- **Forward & Reverse Parking:** Different parking orientations across levels.
- **AI Pedestrian Navigation:** Implemented pedestrian movement using waypoints and Unity NavMesh navigation.
- **AI Traffic System:** Includes AI-controlled vehicles moving around the parking environment.
- **Parking Validation:** The parking area changes from red to green when the vehicle is correctly parked.
- **Level Timer:** Each level has its own timer.
- **Time-Based Scoring:** Tracks player performance based on time.
- **Level Configuration:** Uses ScriptableObjects to configure levels.
- **Asynchronous Scene Loading:** Loads scenes asynchronously.
- **Game Management:** Handles gameplay and level progression.

## 🕹️ How to Play

1. Control the car and navigate through the parking area.
2. Find the designated parking space.
3. Carefully drive into the parking space, following the required forward or reverse parking direction.
4. Position the car correctly inside the parking area. The indicator changes from red to green when parking is successful.
5. Complete the parking challenge within the level's timer to progress through the levels.
